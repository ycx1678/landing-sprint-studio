# Plan B: $49 Landing Page Audit

The fastest alternate revenue path is a small paid audit, not another full build offer.

## Why This Is Faster

- Lower commitment than a $249-$799 build.
- Buyer only needs to send a URL.
- Delivery can be done in under an hour.
- It creates a natural upsell: credit the $49 toward a full build.
- It works for warm network, Reddit, LinkedIn, Twitter/X, indie maker communities, and Upwork replies.

## Offer

**$49 Quick Audit**

- Review one landing page.
- Deliver a written scorecard.
- Give 5 prioritized fixes.
- Include one revised headline and CTA suggestion if obvious.
- Deliver within 24 hours when queue is open.
- Credit the $49 toward a paid landing page build.

**$99 Audit + Copy**

- Everything in Quick Audit.
- Hero rewrite.
- CTA rewrite.
- Section order recommendation.

- founders running ads to an unproven page,
- local businesses with a page that is not getting inquiries,
- creators launching a workshop or product,
- freelancers with a service page,
- early-stage startups that cannot justify a full redesign yet.

## Delivery Workflow

1. Receive URL and goal.
2. Capture desktop/mobile screenshots.
3. Score the page on clarity, CTA, trust, mobile scan path, and friction.
4. Write 5 prioritized fixes.
5. Add one optional upsell paragraph:

```text
If you want me to implement the highest-impact fixes, I can credit this audit fee toward the Starter landing page build.
```
