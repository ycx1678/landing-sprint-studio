# Kmong Service Draft

## 제목

24-48시간 안에 반응형 랜딩페이지를 제작해드립니다

## 한줄 소개

상품, 서비스, 클래스, 매장 홍보에 바로 사용할 수 있는 깔끔한 원페이지 랜딩페이지를 제작합니다.

## 상세 설명

랜딩페이지가 급하게 필요하지만 어디서부터 시작해야 할지 막막한 분들을 위해, 핵심 메시지와 CTA가 분명한 원페이지 웹페이지를 제작합니다.

제작 가능 예시:

- 소상공인/매장 소개 페이지
- 클래스/워크숍 모집 페이지
- 스타트업 MVP 소개 페이지
- 프리랜서/컨설턴트 서비스 페이지
- 이벤트/프로모션 페이지

기본 제공:

- 반응형 HTML/CSS/JS 파일
- 최대 5개 섹션 구성
- 문의/예약 CTA 버튼
- 기본 SEO 제목/설명
- 수정 1회

추가 가능:

- 문구 다듬기
- 예약/문의 폼 연결
- 감사 페이지
- 빠른 납기

진행 전 필요한 자료:

- 로고
- 상품/서비스 설명
- 원하는 문의 방식
- 이미지 또는 참고 사이트
- 공개 가능한 후기/성과

## 가격 제안

- 기본형: 30만원
- 표준형: 60만원
- 긴급형: 90만원

## 주의 사항

의료, 법률, 금융 등 규제 산업의 확정적 효능/수익/법률 판단 문구는 작성하지 않습니다. 제공 자료에 대한 저작권과 사용 권한은 의뢰인이 확인해야 합니다.
