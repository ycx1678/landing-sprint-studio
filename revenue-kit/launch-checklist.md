# Launch Checklist

## 0-30 Minutes

1. Open `index.html` in the project root and review the landing page.
2. If publishing through GitHub Pages, keep the GitHub issue CTA. Otherwise replace the CTA with your email, KakaoTalk, Calendly, or preferred contact link.
3. Zip and upload `product/ai-review-dm-kit` to Payhip.
4. Use `platform-listings/payhip-product-listing.md` as the product page copy.
5. Set the launch price to **$19**.

## 30-60 Minutes

1. Create one marketplace listing for the landing page sprint:
   - Upwork Project Catalog if you already have Upwork,
   - Fiverr Gig if you already have Fiverr,
   - Kmong if you sell in Korean.
2. Use the matching file in `platform-listings/`.
3. Add the landing page screenshot or the root `index.html` as portfolio evidence.
4. Set delivery time to **1 day** for the starter package and **2-3 days** for higher packages.

## 60-120 Minutes

1. Send 10 manual messages to people who already know you or businesses where contact is clearly invited.
2. Do not automate mass email or DM sending.
3. Track replies in a simple spreadsheet.
4. For each warm reply, send the short intake questions from `freelance-service/client-intake.md`.

## First Paid Order Fulfillment

1. Confirm scope and payment platform before starting.
2. Collect copy, logo, links, contact details, and preferred style.
3. Build one static page first; show a screenshot for approval.
4. Include one revision round.
5. Deliver final HTML/CSS/JS or publish to the client's hosting if explicitly agreed.

## Daily Rhythm Until First Sale

- Morning: send 5 manual warm messages.
- Afternoon: submit 2 personalized marketplace proposals.
- Evening: improve one asset based on objections or replies.
